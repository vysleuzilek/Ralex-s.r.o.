# Ralex S.R.O — naše appky

Web pro GitHub Pages. Přehled appek → klik → stránka appky s fotkou z mobilu, z PC a videem.
Appky, fotky i videa se přidávají přímo na webu — stránka je sama uloží do tohohle repa.

## Soubory
```
index.html   přehled appek + přidávání/úpravy
app.html     stránka appky
gh.js        ukládání do GitHubu
style.css    vzhled
apps.json    seznam appek (upravuje se sám)
apps/<id>/   fotky a videa appek (nahrávají se samy)
```

## Přidání appky
1. Na webu klikni na **+**.
2. Poprvé tě to požádá o GitHub token (návod je přímo v okně, dělá se jednou na každém zařízení).
3. Vyplň název, odkaz, popis a vyber logo, fotku z mobilu, fotku z PC a video.
4. **Uložit** → web se obnoví do minuty.

Úprava: podrž appku (na PC pravé tlačítko), nebo na stránce appky klikni na **Upravit**.

## Limity
- Video max 95 MB (limit GitHubu). Delší video dej na YouTube a vlož odkaz.
- Velké fotky se před nahráním samy zmenší.
- Token je uložený jen v prohlížeči, kde ho vložíš. Kámoš si udělá vlastní (musí být přidaný jako collaborator v repu).
